# Color Lock Deluxe — Play Store Setup

## App identity
- App name: Color Lock Deluxe
- Package: com.colorlock.deluxe
- Version: 1.0 (versionCode 1)
- Category: Game > Puzzle
- Suggested short description: Match colors, beat obstacles, collect coins and solve 50 puzzle levels.
- Suggested full description: Color Lock Deluxe is an original color-matching puzzle game with 50 levels, obstacles, coins, hints, lives and satisfying animations. Solve each board, collect coins and improve your best score.

## Build
Open this project in Android Studio and build a signed Android App Bundle (.aab) for Google Play.
Target SDK is set to API 36.

## Play Console
Create app → choose Game → Free/Paid → add support email → complete declarations → store listing → app content → testing → production release.

## Before production
1. Test on several Android phones.
2. Add your real support email and privacy-policy URL.
3. Complete Data safety and content rating questionnaires truthfully.
4. Create a signed AAB and enable Play App Signing.
5. Add store icon/screenshots and feature graphic.
6. If monetization/ads are added later, update Data safety and ad declarations as required.
